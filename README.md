# Money apk

Приложение для отслеживания трат: тонкий Android-клиент + бэкенд на своём VPS.

## Архитектура (кратко)

- Backend: Python/FastAPI + PostgreSQL, HTTPS, JWT-авторизация. Вся бизнес-логика и БД — на сервере.
- Android-клиент: Kotlin + Jetpack Compose, ходит в API по HTTPS.
- Валюта: EUR (регион — ЕС).
- Источники данных: ручной ввод + импорт PDF-выписок банков (парсер под каждый банк отдельно).
- Категоризация трат: словарь ключевых слов + личные правила пользователя (самообучение на правках). ML/LLM-fallback — после MVP.
- Веб-клиент — планируется позже, на том же API.

Подробный план и зафиксированные решения — в проектной документации (docs/plan.md).

## Ветвление

Работаем от `main`, каждая фича/этап — в отдельной ветке: `feature/<название>`.
Ветка сливается в `main` после того, как фича согласована и готова.
